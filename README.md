# Etch-a-Scretch Game

## Overview 📖
You need a short break to have stress free time? Scretch the cells into the colors, paint anything you want! \
Logic of the game to scretch selected cells into color that was chosen. You will have selections such as cell counts, colors.
The project is developed fully in Vanilla JS, Advanced HTML and Responsive CSS


## Technologies 💻
| Field | Languages |
|------:|-----------|
|Web Development | HTML|
|Styling | CSS    |
|Front-End | JavaScript    |


## Features 💡
- **Web-Development**: Used Advanced HTML and Responsive&Advanced CSS
- **UI/UX Design**: Advanced CSS techniques with implementation of animation
- **JavaScript**: Developed with medium level of Vanilla Javascript Language
- **Deployment**: The app is hosted on [Render](https://render.com/), providing a reliable and easily accessible live version of the site.

  

## Installation ⚙
To run this app locally:
1. Clone the Repisotory:
```
git clone git@github.com:mimisha25/Etch-a-Scretch-TOP.git
```
2. Open the project folder
```
cd Etch-a-Scretch-TOP
```
3. Start the application:
- The application run on port 3000 by default. Run the application:
```
open index.html
```
